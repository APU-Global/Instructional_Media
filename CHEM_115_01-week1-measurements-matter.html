Accuracy vs. precision

Accurate means close to the true value. Precise means repeated measurements agree with each other.

The rules

1. Non-zero digits always count.
2. Zeros between non-zero digits count.
3. Leading zeros never count.
4. Trailing zeros count only if the number has a decimal point.

Significant figures show how precisely a value is known.
