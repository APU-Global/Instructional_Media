Week 5 Interactive: Hypothesis Testing

Week 5 objective: Translate a public health question into testable hypotheses and choose an appropriate statistical test.

Six steps to a hypothesis test

  1. Set the significance level (α = .05).
  2. State the research question and hypotheses.
  3. Select the appropriate test.
  4. Define the decision rule (reject H0 if p ≤ .05).
  5. Conduct the analysis.
  6. Interpret results and conclude.

The scenarios use variables from the course Signature Assignment Dataset (for example BMI, CVD and Diabetes risk scores, Gender, Race, Hypertensive, Stroke).

Practice 1: choose the test

Match each question to the test its variable types call for.

Practice 2: hypotheses and decisions

Choose the best answer.

Takeaway: State H0 as no difference or no relationship, set the rule before the data, and let the outcome and factor types choose the test.
