Week 3 Interactive: Building a Better Data System

Week 3 focus: How epidemiological data become public health action, and how to balance the need for data with individual rights (Discussion 3).

Five principles for an ideal public health data system

Kadakia and DeSalvo propose five principles. Select each to see what it means.

Practice 1: Which principle would fix this problem?

Each scenario is fictional. Choose the principle that most directly addresses the problem.

Practice 2: How much data does the task need?

Most public health functions can use anonymized data; some require individual-level data. Classify each task.

Takeaway: Good epidemiology needs data that are equity oriented, actionable, interoperable, collaborative, and backed by a strong public health system. Using the least identifying data a task needs is one practical way to respect individual rights.

Principles and examples from Kadakia, K. T., & DeSalvo, K. B. (2023). Transforming public health data systems to advance the population's health. The Milbank Quarterly, 101(S1), 674–699. Scenarios are fictional.
