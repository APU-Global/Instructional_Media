Week 3 Interactive: Mobile Sites and Apps

Week 3 objective: Decide when a responsive website is enough and when an app earns its place, and design for how mobile visitors behave.

Responsive site, app, or both

A responsive website changes its layout to fit the device, so one build serves desktop, tablet, and phone; Google recommends responsive sites as best practice. An app makes sense when users need something location-specific, push messages, graphics-heavy features, or secure storage of sensitive information, and when the audience will keep using it. An app will not fix a website that gets no traffic. Mobile visitors are usually task driven, time sensitive, and location aware.

Practice 1: what should the church build?

Hillcrest Community Church (fictional) is deciding how people will reach it on their phones. Choose the better fit for each situation.

Practice 2: what does this mobile visitor need?

Mobile visitors are task driven (one specific goal), time sensitive (they need it fast), or location aware (where they are shapes what they need). Choose the best description of each visitor.

Takeaway: Start with the visitor, not the technology. Build a responsive site everyone can use, and add an app only when it solves a real, recurring need that people will come back for.
