Original or Secondary? The File Drawer Problem

An original study reports new data; a secondary source summarizes or interprets existing studies. Sort real-world sources, then run a simulation to see how unpublished studies can skew what the published literature seems to show.

Part 1 · Which kind of source?

Original researchThe first published account of a study: methods, sampling, analysis, findings, limitations. A primary source.
Secondary sourceSummarizes or interprets original research (textbooks, reviews, websites, news). Can omit key information.
Secondary data analysisA researcher analyzes data someone else collected, such as a national survey.

Part 2 · The file drawer problem

Studies that reach statistical significance are more likely to be published, so studies without significant results can end up in a “file drawer.” This simulation runs 100 studies (30 participants per group) of the same effect. Chance makes each result vary. Choose the true effect and how often non-significant studies get published.
