Step 1: Which system shows it?

Dashboards give the public outcome data; an EIS tracks officer-level warning signs. (Dallas's public Transparency and Accountability Dashboard, for example, shows complaint types, complainant demographics, resolution outcomes, and officer commendations.) Choose where each item belongs.

Step 2: Test each explanation

Crime is down while risk flags are up. For each possible explanation, pick the data that would test it best.

Step 3: Advise leadership

What should the chief do first?

Takeaway: A dashboard and an EIS answer different questions, so they can move in different directions without either being wrong. List possible explanations, test each one with data, treat EIS flags as signals for support and review rather than findings of misconduct, and communicate both trends honestly to build public trust.
