Week 5 Interactive: IPv6 Readiness Inventory

Week 5 objective: Identify the parts of an IPv4 network that must change before an IPv6-only move, and decide what each needs.

What changes

DNS
Each host reached over IPv6 needs an AAAA (IPv6 host) record, the counterpart of the A record. IPv4 reverse lookups use in-addr.arpa; IPv6 reverse zones use ip6.arpa.
DHCP
Windows Server DHCP can assign IPv4 and IPv6 addresses, but IPv6 service is configured separately. Plan scopes, reservations, options, and relay agents.
Static settings and rules
Hand-entered addresses, firewall rules, and scripts that name IPv4 addresses must be found and updated.
IPv6 in Windows
IPv6 is a mandatory part of Windows. Microsoft recommends the “Prefer IPv4 over IPv6” prefix policy instead of disabling IPv6. IPAM can discover your DHCP and DNS servers for the inventory.

Takeaway: An IPv6-only move touches every service that names an address: DNS records and reverse zones, DHCP scopes and options, static settings, firewall rules, and scripts. Inventory them all, keep IPv6 enabled, and plan testing and training before the cutover.
