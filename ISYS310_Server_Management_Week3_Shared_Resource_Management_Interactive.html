Week 3 Interactive: Account and Resource Management

Week 3 objective: Control who can use a shared folder with Active Directory groups, then control what and how much is stored there with File Server Resource Manager (FSRM).

Your toolkit

Group-based permissions
Users join global groups, global groups join domain local groups, and the share grants access to the domain local group.
Quota
Limits the space a volume or folder may use and notifies people as the limit nears. Auto apply quotas and templates spread the rule.
File screen
Controls which file types users can save and can notify you of attempts. Exceptions allow specific needs.
File management task
Finds files by location, classification, or creation, modified, or last-accessed time and acts on them, such as expiring them, on a schedule; can notify owners first.
Storage report
Shows disk-usage trends and can monitor attempts to save unauthorized files.
Note
FSRM works on NTFS volumes only.

Practice: pick the right tool

Scenarios are fictional. For each problem, choose the tool that fits best, then select Check my answers.

Takeaway: Fix who can write to a share with group-based permissions, then manage what and how much they store with quotas, file screens, file management tasks, and storage reports. Communicate the policy so people know why the share is changing.
