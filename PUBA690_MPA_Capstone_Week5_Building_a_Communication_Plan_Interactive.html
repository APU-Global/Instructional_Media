Week 5 Interactive: Building a Communication Plan

Week 5 objective: Plan how your implementation will be communicated to each stakeholder group, as Discussion 5 and Capstone Project Part 3 ask.

Part 1: Put the steps in order

The Community Tool Box describes an eight-step process for planning communication. Use the arrow buttons to put the steps in order.

    Part 2: Name the plan element

    Riverbend (fictional) is launching a night bus route. Identify which part of the communication plan each item is.

    Part 3: Make the better choice

    Choose the option that best follows the Community Tool Box guidance.

    Takeaway: Plan communication before you launch: know your purpose and audiences, tailor the message and messenger, prepare for problems, and check whether people understood. "Write the vision; make it plain on tablets, so he may run who reads it" (Habakkuk 2:2, ESV).
