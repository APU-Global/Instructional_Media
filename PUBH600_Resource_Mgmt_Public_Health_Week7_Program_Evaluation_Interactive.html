Week 7 Interactive: Evaluation, Accountability, and Improvement

Week 7 objective: Apply CDC's Program Evaluation Framework to plan an evaluation of a public health program.

The scenario

Breathe Easy Homes is a fictional county program that sends community health workers to homes of children with asthma to reduce triggers. The health department asks you to plan its first evaluation using CDC's Program Evaluation Framework.

  • 6 steps guide the evaluation.
  • 3 cross-cutting actions: engage collaboratively, advance equity, and learn from and use insights.
  • 5 standards: relevance and utility, rigor, independence and objectivity, transparency, ethics.

Practice 1: put CDC's six steps in order

Use the arrow buttons to move each step. Then select Check my order.

    Practice 2: what does the question ask about?

    CDC's Action Guide lists five kinds of questions evaluation can answer. Match each Breathe Easy question.

    Practice 3: evaluation, research, or monitoring?

    CDC distinguishes evaluation from related activities. Name the activity described.

    Takeaway: Good evaluation starts with context and a clear program description, asks a focused question, and ends with action. Monitoring tells you that performance changed; evaluation helps explain why and what to do next.

    Steps, cross-cutting actions, standards, question types, and definitions from Centers for Disease Control and Prevention, CDC's Program Evaluation Framework Action Guide (2024) and CDC Program Evaluation Framework (web page, 2024). Breathe Easy Homes is fictional.
