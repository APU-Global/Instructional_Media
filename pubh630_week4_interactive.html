Build a Logic Model

A logic model is a hypothesis, not a guarantee. Assemble one for a neighborhood walking program, stress-test its assumptions, then choose indicators for each part.

Part 1 · Assemble the model

Select a card, then select the column where it belongs (or press its number key once a card is selected). Inputs are resources; activities are what the program does; outputs are direct products; outcomes are changes over time.
