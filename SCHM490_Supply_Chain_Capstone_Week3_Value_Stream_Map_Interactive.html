Week 3 Interactive: Walk the Value Stream

Week 3 objective: Use value stream mapping to find waste, measure process efficiency, and design a future state that can handle mass customization.

The scenario

Ridgeline Bikes (a fictional company) builds bicycles to order: customers choose a frame size, paint color, and handlebar style online. Orders now take too long to ship, and the plant is crowded. You join the team mapping the current state before designing a future state.

Step 1: Spot the seven wastes

Each observation comes from the team's walk through the plant. Choose the type of waste it shows, then select Check my answers.

Step 2: Measure process efficiency

The current state map shows how long work is actually done on one bike at each step (operation time), and how long an order takes from release to shipping (lead time).

Step 3: Design the future state

Check the three changes that best cut waste while keeping Ridgeline's custom options, then select Check my plan.

Step 4: Put the mapping steps in order

Use the arrow buttons to order the steps of a value stream mapping project, then select Check order.

    Takeaway: A value stream map makes waste visible. Compare operation time with lead time to see how little of the flow adds value, then target lead time, inventory, and cycle time. With mass customization, modules, consistent supplier specifications, and fast order information keep variety from becoming waste.
