Week 1 Interactive: Installation Choice

Week 1 objective: Choose a Windows Server 2016 edition and installation option by weighing roles, virtualization, storage, management skills, and security, not just the number of users.

Two decisions, not one

EDITIONStandard or Datacenter?
  • Users are licensed by CALs in both editions.
  • File and Storage Services, AD DS, DNS, DHCP, print, and Windows Server Backup are in both.
  • Standard: 2 virtual machines plus one Hyper-V host per license.
  • Datacenter: unlimited virtual machines, plus Storage Spaces Direct, Storage Replica, Host Guardian Hyper-V Support, and Network Controller.
INSTALLATION OPTIONServer Core or Desktop Experience?
  • Server Core: no standard graphical interface; managed with PowerShell, SConfig, or remote tools; smaller disk footprint; greatly reduced attack surface. Microsoft recommends it unless you need the graphical tools.
  • Desktop Experience: the full graphical interface, Server Manager, and the Microsoft Management Console.
  • You can't convert between them after installation; changing requires a clean install.

Takeaway: The user count rarely decides the edition. Ask what roles and features the server needs, how many virtual machines it will host, and who will manage it, then choose Server Core unless you truly need the graphical tools, because you can't switch later without a clean install.
