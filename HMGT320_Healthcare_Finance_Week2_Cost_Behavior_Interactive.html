Week 2 Interactive: Cost Behavior and Resource Allocation

Week 2 objective: Examine managerial concepts germane to healthcare organizations, including cost allocation and profit analysis.

Three cost patterns

A variable cost changes in total with activity but stays the same per unit. A fixed cost stays the same in total, so its cost per unit falls as volume rises. A mixed cost has both parts: total mixed cost = total fixed cost + (unit variable cost × number of units). Below, the activity is the number of scans at fictional Harbor View Imaging.

Decide how each cost behaves as the number of scans changes.

Part 2: Run the numbers

Part 3: Allocate a constrained resource

Harbor View's MRI scanner has a fixed number of hours each week. Service A earns a contribution margin of $300 per scan and takes 2 scanner hours. Service B earns $200 per scan and takes 1 scanner hour.

Takeaway: Know how each cost behaves before you commit resources: fixed costs stay in total, variable costs move with volume, and mixed costs do both. When a resource is limited, compare options per unit of that resource, then weigh qualitative factors such as patient need and mission before deciding.
