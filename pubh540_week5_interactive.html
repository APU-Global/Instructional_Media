Outbreak Lab

The basic reproduction number estimates how many people one case may infect in a susceptible population. Run an outbreak, raise immunity, and see why speed, accuracy, and honest communication all matter.

Part 1 · Run an outbreak in a town of 400

Each person is a square. Choose R₀ (how many others one case would infect if everyone were susceptible) and how many people are immune through vaccination. Then start the outbreak. Each run is random, so try it a few times.
