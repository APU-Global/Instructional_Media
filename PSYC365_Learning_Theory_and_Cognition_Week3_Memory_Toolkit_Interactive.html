Week 3 Interactive: Types of Memory and Strategies That Work

Week 3 objective: Identify types of memory and match evidence-based study strategies to everyday situations.

What the readings say

Stangor divides long-term memory into explicit memory, which we can consciously recall (episodic memories of our own experiences and semantic knowledge of facts), and implicit memory, which shapes behavior without awareness (procedural skills, conditioning effects, and priming). His chapter on improving memory lists strategies with research behind them: elaborative encoding, the self-reference effect, spacing, and context-dependent retrieval. McDermott and Roediger add the testing effect: retrieving a memory makes it more likely to be retrieved again. Short-term memory holds only about five to nine items, but chunking stretches that limit.

Takeaway: Memory improves when you space your study, test yourself, and connect new ideas to your own life. Rereading feels productive, but retrieval is what makes memories last.
