Week 3 Interactive: Phonology and Literacy

Week 3 objective: Use phonemes, minimal pairs, and syllable structure to explain how children move from sounds to reading.

Key terms

Phoneme: a sound category speakers treat as one sound (the t in atom and atomic are two allophones of /t/)Minimal pair: two words that differ in only one sound, like pill and killSyllable: an optional onset, a nucleus (usually a vowel), and an optional coda

Practice 1: Is it a minimal pair?

Say each pair aloud and listen to the sounds, not the spelling. A minimal pair has the same sounds in the same order except in one position.

Practice 2: Map the syllable

Choose the CV pattern for each one-syllable word: C for each consonant sound in the margins, V for the nucleus. Remember to count sounds, not letters.

Practice 3: Stack the building blocks of reading

Use the arrow buttons to put the layers in order, from the foundation (1) to the top (4).

    Practice 4: Which building block is the child practicing?

    Each child is fictional. Choose the layer each activity practices.

    Takeaway: Reading builds on the sound system children already have. Minimal pairs show which sounds change meaning, syllables give readers chunks to decode, and reading skills stack from concepts of print to phonemic awareness to decoding to fluent reading.
