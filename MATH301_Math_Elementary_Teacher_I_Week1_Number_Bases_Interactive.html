Week 1 Interactive: Place Value in Any Base

Week 1 objective: Change numerals between base ten and other bases, and see place value the way a child learning "ten" sees it.

The big idea

In base ten, ten ones make a ten and ten tens make a hundred, so 706 means 7 hundreds, 0 tens, and 6 ones. Every base works the same way. In base five, five ones make a "five" and five fives make a "twenty-five," so the places are 1, 5, 25, 125, and so on. A base-b numeral uses only the digits 0 to b − 1.

Bundle explorer

Choose a base and a base-ten number. The explorer bundles the ones into groups, the way children bundle straws into tens.

 

Practice: convert each numeral

Type your answer (digits only), then select Check my answers. Subscripts show the base: 213five means 213 in base five.

Quick check: could this numeral exist?

A base-b numeral can only use the digits 0 to b − 1. Decide whether each numeral is possible.

Takeaway: Every place is a bundle of the place to its right: ones, then a bundle of ones, then a bundle of bundles. To change to base ten, multiply each digit by its place value and add. To change from base ten, take out the largest place values first. When base five feels strange, remember: that is how "ten" feels to a first grader.

Place-value ideas from the California Common Core State Standards: Mathematics (California Department of Education, 2013), standards 1.NBT.2 and 2.NBT.1, and the Mathematics Framework for California Public Schools (2024), Chapter 3 "Number Sense." This activity practices the skills in Blitzer, Thinking Mathematically, Section 4.2 (Number Bases in Positional Systems).
